The Ember Quest
This repository contains the source code and all necessary assets for the bachelor's degree project, "The Ember Quest," developed by Andreea-Catalina Ghiocel.
This document provides detailed instructions on how to properly download, open, and run the project using Unity Engine.
Project Submission Date: June 28, 2025

System Requirements
* Unity Version: Unity 6.1 [Build 6000.1.0f1]
* Git & Git LFS: This project uses Git Large File Storage (LFS) to manage large assets. Both Git and the Git LFS extension are required to download the project correctly.

Download and Setup Instructions
To ensure the project is downloaded correctly, please follow these steps precisely. Using the "Download ZIP" button on GitHub will not work as it does not support Git LFS, which will result in a broken project.

Step 1: Install Required Software
1. Install Git: If you don't have Git, download and install it from git-scm.com.
2. Install Git LFS: If you don't have Git LFS, download and install it from git-lfs.github.com.
3. Setup Git LFS: After installing, you must run the following command once in your terminal or command prompt to initialize Git LFS on your machine:
git lfs install

Step 2: Clone the Repository
   1. Open your terminal, Command Prompt, or Git Bash.
   2. Navigate to the directory where you would like to store the project using CD "File Path" or by *right-click* & select "Open Git Bash Here" in the folder where you want to download the project.
   3. Run the following command to clone the repository. This will create a folder named TheEmberQuest and correctly download all project files, including the large assets handled by Git LFS.
git clone https://github.com/XsnowdropX/TheEmberQuest.git

Running the Project in Unity
      1. Open Unity Hub.
      2. In the "Projects" tab, click the Open button (or "Add project from disk").
      3. Navigate to the TheEmberQuest folder that was created in the previous step and select it.
      4. Unity will begin importing the project. This may take several minutes, as it needs to process all assets.
      5. Once the project is open, you can find the main scene to run the game in the Project window under [Enter Path to Main Scene, e.g., Assets/Scenes/Main.unity]. Double-click it to open, then press the Play button at the top of the editor.
